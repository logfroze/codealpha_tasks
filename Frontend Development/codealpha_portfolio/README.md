# CodeAlpha Developer Portfolio Site

A responsive, professional personal developer portfolio built entirely with **HTML5, CSS3, and modern JavaScript (ES6)**. Designed and hand-crafted as part of the **CodeAlpha Frontend Development Internship (Task 3)**.

---

## 📌 Overview

This project showcases a solid, hand-coded developer portfolio with clean architecture, accessible markup, dark/light theme persistence, and zero external framework dependencies. It presents technical competencies, selected production projects, CodeAlpha internship achievements, open-source repositories, and verified recommendations.

---

## 🧭 Sections Included (8 Sections)

1. **Home (Hero)**: Highlighting professional title, credentials, quick statistics, call-to-action buttons, and developer profile picture.
2. **About**: Career summary, developer philosophy, background story, and quick structured details (Degree, location, experience, languages).
3. **Skills**: Categorized technical skills across Frontend Engineering, Backend & Cloud, Programming Languages, and Tools & Workflow.
4. **Projects**: Selected real-world client platforms and startup projects with interactive category filtering (`All`, `Websites`, `Business`, `Portfolio`).
5. **Internships**: Featured CodeAlpha 1-Month Internship showcase with dual-track filters (**FrontEnd Development** & **Python Programming**) and 7 project cards with live links and preview images.
6. **GitHub**: Open-source overview, repository statistics, featured repositories, and direct profile integration (`@logfroze`).
7. **Testimonials**: Verified client reviews and recommendations from businesses and collaborators.
8. **Contact**: Direct communication channels (Email, Phone, Location, LinkedIn) with a responsive, client-side validated contact form.

---

## 🛠️ Technologies Used

- **HTML5**: Semantic structure, accessible landmarks, and clean element hierarchy.
- **CSS3**: Custom properties (CSS variables), Flexbox, CSS Grid, media queries, and dark/light color schemes.
- **JavaScript (ES6+)**: Vanilla DOM manipulation, scrollspy navigation, mobile drawer toggle, dynamic category filtering, theme persistence via `localStorage`, and form submission handling.
- **Font Awesome (CDN)**: Vector icons for intuitive interface navigation.
- **Google Fonts**: Plus Jakarta Sans & JetBrains Mono typography pairing.

## ✨ Key Features

- **Natural & Solid Aesthetic**: No distracting blur or excessive animations; clean, readable, professional UI.
- **Dark & Light Mode**: Built-in toggle with persistent `localStorage` support.
- **Dual-Track Internship Showcase**: Complete documentation of the CodeAlpha 1-month program with 7 project deliverables.
- **Interactive Project Filtering**: Switch between project domains instantly without page reloads.
- **Mobile-Responsive**: Fully tested across mobile, tablet, and widescreen desktop displays.
- **Zero Frameworks**: 100% hand-crafted vanilla web technologies.

## 🚀 Getting Started / How to Run

1. Clone or download the repository:
   ```bash
   git clone https://github.com/logfroze/CodeAlpha_Portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd CodeAlpha_Portfolio
   ```
3. Open `index.html` in any modern web browser directly (double-click or right-click > Open With Chrome/Firefox/Edge), or serve via any static HTTP server (e.g., Live Server in VS Code, `npx serve`, or Python's `python -m http.server`).
