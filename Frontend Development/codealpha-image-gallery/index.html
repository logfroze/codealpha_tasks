Crafted Specifications

This interactive gallery was developed as part of the CodeAlpha Frontend Development Internship. The goal was to build a clean, responsive, and accessible image gallery using standard web technologies without external framework overhead.

CodeAlpha Internship Track: Task 01 • Responsive Web Design • Vanilla JavaScript DOM • Lightbox Architecture

Fluid CSS Grid Layout

Adaptable grid with editorial aspect ratios that gracefully transitions from 1 column on mobile to 3 columns on large desktop screens.

Filter-Aware Lightbox

Seamlessly respects category filtering. When filtered to Nature, previous/next controls cycle solely through visible Nature works.

Keyboard Navigation

Full physical keyboard accessibility with Arrow Left, Arrow Right, and Escape key listeners, plus touch swipe support on phones.

Zero Bloat Vanilla Core

Implemented with lightweight semantic HTML5, pure CSS3, and vanilla JavaScript without external libraries or runtimes.
